1. Flujo colaborativo
Supón que quieres colaborar con el repositorio de otro desarrollador. Ordena y explica los siguientes elementos:
Push, Fork, Pull Request, Clone, Merge, Commit, Review, Branch y Modificar archivos. Agrega cualquier
operación que consideres necesaria.

# Fork 
Crea una copia de un repositorio en mi cuenta
# Clone
Crea una copia del repositorio anterializado un fork
# Branch
Se crea una rama nueva para hacer los cambios en ella y despues hacer pull request
# Modificar archivos
En la nueva rama se modifican los archivos
# Commit
Prepara los archivos para ser subidos al repositorio
# Push
Termina de subir los archivos al repositorio
# Pull request 
Envia una solicitud de cambios al dueño del repositorio para que sea aceptada o rechazada
# Review
Revisa cambios del pull request antes de ser aceptado
# Merge
Acepta los cambios propuestoa por el colaborador
